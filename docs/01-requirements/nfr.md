# НФВ, узгоджені зі стеком

Задача PIS-17. З опису: час відповіді, fail-closed аудит, локальний запуск.

Стек уже зафіксовано рішенням D8 формалізації етапу 1: Python (FastAPI), PostgreSQL, React (Vite), паролі bcrypt. Ця задача фреймворк інтерфейсу не обирає і D8 не скасовує. Нижче лише те, як три названі НФВ сідають на цей стек.

Чернетка розділу 8.4 дає стелю: запит лікування по синтетичному Bundle до 50 ресурсів на локальному запуску повертає рішення не довше ніж за 3 секунди. Для локального прототипу на FastAPI і PostgreSQL ціль тісніша і вже зафіксована як рішення PIS-17: 500 мс на лікування і 2 с на дослідницький знімок. React (Vite) у цей час не входить: поріг міряється на відповіді API.

## Час відповіді

Міряти на машині розробника. FastAPI, PostgreSQL і React працюють на `localhost`. Обмін між закладами в прототипі імітується локально.

| Операція | Поріг |
| --- | --- |
| Лікування: перевірка згоди, читання EHR, запис аудиту, відповідь Bundle до 50 ресурсів | не довше 500 мс, і в будь-якому разі не довше 3 с із чернетки 8.4 |
| Дослідницький знімок до кількох десятків пацієнтів, включно з відмовою якщо пацієнтів менше ніж 5 | не довше 2 с |
| Відмова доступу без клінічного тіла | не довше 500 мс |

Час запису аудиту входить у поріг. Якщо поріг зірвано, дані без журналу не віддаються.

## Fail-closed аудит

Рішення про видачу і рядок аудиту фіксуються однією транзакцією PostgreSQL.

- Якщо `INSERT` аудиту не пройшов, транзакція відкочується. API не повертає FHIR Bundle і не повертає клінічні поля в тілі помилки.
- Якщо PostgreSQL недоступна, обмін зупиняється. Окремого шляху повз журнал немає.
- Немає режиму «віддати дані, журнал дописати пізніше».
- Застосунок не виконує `UPDATE` і `DELETE` рядків журналу.
- Відмова через згоду, роль або поріг групи теж лишає слід у журналі. Якщо не вдалося записати навіть відмову, відповідь — помилка без клінічних даних.

## Локальний запуск

Один локальний екземпляр. Окремої відмовостійкої схеми немає.

- PostgreSQL на `127.0.0.1:5432`. Рядок підключення і секрет псевдонімізації беруться з `.env`. У Git лежить лише `.env.example`.
- API: `uvicorn` на `http://127.0.0.1:8000`, коли з’явиться код обміну.
- UI: React (Vite) на `localhost`, звертається лише до цього API.
- На `localhost` допускається HTTP. Будь-яке розгортання поза машиною команди — лише з TLS.

Коду сервера і фронтенда в цьому коміті немає. Команди вище — контракт запуску, не інструкція, яка має спрацювати зараз.
