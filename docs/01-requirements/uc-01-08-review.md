# Вичитка UC-01…UC-08

Задача PIS-13. Чернетка для підтвердження командою. Джерело — специфікації розділу 8 формалізації етапу 1. Поки Дидик і Коваль не підтвердили рядки нижче, вичитка не закрита.

## Актори, яких просимо підтвердити

| Актор | Тип | Роль у прототипі |
|---|---|---|
| Пацієнт | людина | дає і відкликає згоду, бачить лише свої події |
| Лікар закладу-отримувача | людина | запитує дані для лікування, за потреби відкриває аварійний доступ |
| Дослідник | людина | отримує один псевдонімізований знімок у межах дозволу |
| DG-адміністратор | людина | видає дозвіл, читає весь журнал, за окремим аудитом відкриває сховище відповідностей |
| Адміністратор закладу | людина | у прототипі без екрана: облікові записи вже в початкових даних |
| EHR закладу-джерела | зовнішня система, імітація | віддає FHIR Bundle після перевірки прав |

Лікаря закладу-джерела окремим актором не виділяємо: дані забирає платформа.

## Виняткові ситуації, яких просимо підтвердити

| Прецедент | Виняток | Очікуваний результат |
|---|---|---|
| UC-01 | обліковий запис вимкнено | сеанс не створюється, DG бачить подію |
| UC-02 | не обрано жодної категорії | згода не зберігається |
| UC-03 | згода вже відкликана або прострочена | статус не перезаписується |
| UC-04 | роль або заклад без права | `deny`, клінічних даних у відповіді немає |
| UC-04 | якість блокує набір | `rejected_quality`, набір не зберігається як клінічні дані |
| UC-04 | журнал не записався | відповідь із даними не відправляється |
| UC-05 | не обрано жодної категорії | дослідницька згода не зберігається |
| UC-06 | дозвіл прострочений, відкликаний або чужий | `deny` |
| UC-06 | після фільтрів менше ніж 5 пацієнтів | `denied_small_cell`, файл не створюється |
| UC-06 | дослідник читає таблицю відповідності | відмова і окремий запис журналу |
| UC-07 | лікар або дослідник відкриває загальний журнал | відмова |
| UC-08 | строк довший за 90 діб або категорія поза прототипом | дозвіл не зберігається |

Аварійний доступ лишається розширенням UC-04, не окремим прецедентом. UC-03 відкликає і лікувальну, і дослідницьку згоду: пацієнт обирає, яку саме.
