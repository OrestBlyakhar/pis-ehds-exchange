# Чекліст дошки PIS

Задача PIS-7. Перевірено 13 листопада 2026 на живій дошці. 23 листопада 2026 на активному спринті знову видно ті самі чотири колонки і жодної іншої.

Проєкт: **ПІС — обмін медичними даними**, ключ `PIS`, team-managed Scrum.

Адреса: https://blyakhar76.atlassian.net/jira/software/projects/PIS/boards/2

| Умова з задачі | Стан |
|---|---|
| Team-managed Scrum | так, стиль проєкту next-gen, тип дошки Scrum |
| Колонка To Do | є, перша |
| Колонка In Progress | є, друга |
| Колонка Review | є, третя; статус у колонці називається Review |
| Колонка Done | є, четверта |
| Інших колонок немає | так, режим дошки спрощений: кожен статус процесу зіставлений з однією колонкою |

Оцінка в story points увімкнена (поле Story point estimate).

Критерій прийняття задачі виконаний самою дошкою: це team-managed Scrum і колонки стоять у порядку To Do / In Progress / Review / Done.
